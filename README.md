# 重庆购物狂 x 十二背后 · 官方合作专区

> 从重庆出发，潜入亚洲第一长洞

## 🌐 在线预览

**访问地址**: https://rey615.github.io/chongqing-shierbeihou/

## 📱 项目介绍

这是一个为重庆购物狂旅游板块打造的十二背后景区官方合作展示页面，包含：

- 🏔️ **三大核心景区**介绍（双河洞、清溪峡、大地缝）
- 🧗 **六大探洞项目**展示（从入门到地狱难度）
- 💰 **交互式预算计算器**（实时计算旅行费用）
- 📊 **可视化预算图表**（甜甜圈图表展示费用分布）

## 🎨 设计特色

- **暗色主题**：深绿色(#0D4A2E) + 金色(#D4A843) 配色
- **玻璃拟态**：毛玻璃效果导航栏和卡片
- **响应式布局**：完美适配桌面端和移动端
- **流畅动画**：滚动渐显、悬停效果、平滑过渡

## 🛠️ 技术栈

- HTML5 + CSS3 (CSS Variables, Grid, Flexbox)
- JavaScript (ES6+)
- Canvas API (预算图表)
- Intersection Observer API (滚动动画)
